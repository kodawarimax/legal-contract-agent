# 契約交渉シミュレーション — 5席モデル (`contract-negotiation-sim`)

契約書の修正案を相手方へ提出する前に、**利害の対立する当事者たちに本気で交渉させ、第三者ジャッジに公平性を裁定させる**ことで、「法的に正しいが関係を壊す修正案（勝ちすぎ）」を提出前に検知します。

## 5席の定義

| 席 | 役割 | インセンティブ |
|---|---|---|
| **S1** | **相手方 当事者AI**（担当者ペルソナ） | 自社の損失最小化＋利益最大化。**感情と社内事情を持つ**: 面子を潰されたり上司に説明できない条項は拒否・決裂宣言する |
| **S2** | **こちら側 当事者AI**（依頼者ペルソナ） | 自社の損失最小化＋利益最大化 |
| **S3** | **相手方の味方 法律家AI** | S1の利益を最大化する敵方リーガル。こちらの修正案の穴・過剰要求を突く |
| **S4** | **こちらの味方 法律家AI** | S2の急所（支払・知財・責任上限・解除）を守りつつ、締結と継続関係に至る修正案を組む |
| **S5** | **第三者ジャッジAI** | 条項バランスシートと判定基準 J1〜J5 で「勝ちすぎ」「決裂リスク」「急所の無防備」を中立裁定する |

## パラメータ

1. **P1 勝ち度合いダイヤル（目標利益配分 自分:相手）**
   - `対等` (50:50 ±5) / `標準` (55:45〜60:40、既定) / `優位確保` (60:40〜70:30) / `防衛優先` (配分不問・急所死守のみ)
   - ※どの設定でも「決裂トリガー（何様条項）ゼロ」と「急所防御」は緩和不可。
2. **P2 前提条件**: 力関係、代替選択肢（BATNA）、関係の性質（単発/継続/戦略）、絶対防衛ライン。
3. **P3 相手プロファイル**: 性格傾向、意思決定スタイル（即断/上司決裁必須）、地雷、コミュニケーション文体。

## 実行フェーズ
1. **Phase 0**: パラメータ確定＋両社の利害マップ作成
2. **Phase 1**: 相手陣営（S1+S3）と自陣営（S2+S4）による条項別評価
3. **Phase 2**: 交渉ラウンド（最大3周：提案→反論/対案→交換条件・段階化による調整）
4. **Phase 3**: 第三者ジャッジ（S5）による条項バランスシート算出＆J1〜J5裁定
5. **Phase 4**: ジャッジ通過版の最終修正案＋Wordコメント文面の出力（注意：シミュレーションの内部経緯や「当初案から譲歩した」等のメタ発言はM13規律により相手向けコメントへ一切出さないこと）
