# 経営者のための法務マインド

> 中小企業経営者が持つべき法的リテラシーと、リーガルアドバイザーの人生哲学・ビジネスにおける心構え。

---

## 契約は経営そのものである

### 雛形の安易な使用は思考停止

- ネット上の雛形や他社の契約書をそのまま流用するのは非常に危険
- 契約書は自社の独自ポジションを取った**オーダーメイド**であるべき
- 他社の契約書は他社のビジネスに合わせて作られたもの → 自社には合わない

### 専門家への丸投げは禁物

- 弁護士は「法的に問題がないか」をチェックしてくれるが、ビジネスの実態や経営判断まで代行しない
- 経営者自身が主体となって契約書の内容を理解し、自分の言葉で相手に説明できる必要がある
- 実務的条件（前半）は社長が交渉し、法的条件（後半）だけ弁護士に選択肢を提示してもらう

### トラブル予防への投資

- 歯医者で定期的にクリーニングするのと同じ → トラブル前に契約条件を整えることが時間とお金の節約
- 下請けなどの弱い立場にいる場合、身を守る唯一の手段は「合意した条件を書面に残すこと」
- 小難しい契約書でなくても、議事録にサインするだけで立派な契約になる

## 言葉の定義と契約の管理

### 用語の厳格な定義

- 「本製品」「本業務」「秘密情報」等の用語は最初に厳密に定義する
- 首尾一貫して同じ用語を使用する
- 一字違い（「対等額」vs「対当額」）で解釈が全く変わる世界

### 定期的な見直しの必要性

- 10年前の条件がそのまま適正であり続ける可能性は極めて低い
- 老朽化したインフラを放置するのと同じ危険
- **自動更新ではなく合意更新**を活用し、定期的に条件を見直す仕組みを取り入れる
- 契約条件と実際の取引がかけ離れている企業が非常に多い

## 相手を見極める判断基準

### 「習慣」に本質が出る

- 相手が信頼に足る人物かは「習慣」に現れる
- 時間に対する考え方（遅刻・ドタキャン）
- お金の支払いスピード（7段階あり、毎回同じパターン）
- メールの返信速度
- 「小さな約束」を守れるかどうか

### 決断力の観察

- 些細なこと（食事、遊びの場所）を素早く決められるか
- 世の幸せな成功者は皆、決断が半端なく早い
- グダグダと決められない相手、合意事項を寸前で取り消す相手とは業務提携が成功しない
- イベントに誘って決断力を観察するのが有効

### お金の支払いスピード

| タイプ | 特徴 |
|-------|------|
| 最速タイプ | 通知を受ける前に秒速で支払い |
| 中速タイプ | 確認後、期限前に余裕をもって支払い |
| スケジュール型 | 自社ルールに従い期限通りに支払い |
| どんぴしゃタイプ | 期限当日にきっちり支払い |
| ついうっかりタイプ | 期限翌日に慌てて支払い |
| どんくさタイプ | 督促されてから支払い |
| 絶対アカンタイプ | 何度督促しても支払わず言い訳 |

## 交渉における人間理解

### 相手のニーズとお困りごとを先に探る

- いきなり価格の話から入らない
- 相手が何を最重要視しているか（納期？品質？知財？）を探り出す
- お困りごとをじっくり聞いて整理し、選択肢を提示してあげる

### 「理由」を添えて伝える

- 人間は事実よりも「理由」を求める生き物
- 契約書の修正案を返す際は、Wordのコメント機能で「なぜこの修正をしたか」の理由を必ず添える
- 理由なしの修正は相手を不快にさせ、交渉が停滞する

### 相手の社内事情を理解する

- 大企業との交渉で「前回合意した条件を変えてくれ」と言われるのは日常茶飯事
- 原因: 担当者が上司・取締役にきちんと説明していなかった
- 正論で責めても逆効果 → 担当者が社内決裁を取るためのサポートをする

## リーガルアドバイザーの人生哲学

### ビジネスの最終目的は「信頼を稼ぐこと」

- 目先のお金ではなく、信頼を稼ぐことが最も重要
- 自分の儲けにならなくても相手にとって本当に良いものを提案する姿勢
- 多少無理してでも相手に「先に」メリットを与えて「貸し」を作る（返報性の法則）
- 先に与えると後で倍返しで戻ってくる → 業務提携でも同じ

### 「良し悪し」よりも「好き嫌い」

- 世間的な評価や法律的な「良し悪し」に縛られて思考停止しない
- 「自分はどうしたいのか?」という自分の感性に素直に向き合う
- 信頼できるビジネスパートナー選びやビジネスの決断において重要
- 「NGかOKか」ではなく「損か得か」で考える

### 「先に言うと説明、後で言うと言い訳」

- 和仁達也先生の名言 → 実務家が深く共感する原則
- 都合の悪いこと、弱点、リスクは先に開示する
- 後から言うと「先に言え!」と信頼を失う
- 契約交渉でも、想定されるリスクを先回りして相手に伝える

### 「小分け主義」と疲労の予防

- **志は高く、やることは小分けに**が鉄則
- 高い目標を持ちつつも、目の前のノルマは限りなく小さく設定する
- すぐに実行して小さな達成感を積み重ねる
- 「しんどいな」と思ったらすぐやめる → 今すぐ5分だけやる
- 疲れる前に休む（疲労の予防）→ 常に高いパフォーマンスを維持

### ゼロベース思考と「あきらめの良さ」

- 「ここまで頑張ったから」とサンクコスト（埋没費用）に囚われない
- 「今ゼロから始めると仮定しても、やる価値があるか?」と問い直す勇気
- 合わない相手や見込みのない交渉にはとっとと見切りをつける
- **あきらめの良さ**も良いご縁に出会うための欠かせない要素

### 「一期一会」よりも「次に会う機会を作る」

- 「これが最後だ」と余裕をなくして情報を詰め込むよりも逆効果
- 「次に会う（交渉する）機会を作るにはどうすればいいか」を考える
- 無理なく相手との信頼関係を深められる
- 情報も小出しにする方が相手の興味を引き続けられる

### 遠い未来を見るマインド

- 理不尽な要求にブチ切れそうになったときの問いかけ:
- **「この相手と20年業務提携することが運命で決まっているとしたら、今自分はどうする?」**
- ブチ切れた後の交渉がうまくいった例は皆無
- 「すごいことを淡々と行う」ことを目指す

### 自社のセルフイメージを明確に

- 判断に迷ったとき立ち返る原点（ミッション・ビジョン）を明確にしておく
- 相手の規模や目先の利益にブレることなく、一貫した行動を取れる
- 「何としても守らなければいけないもの」は経営者の価値観・理念に深く関係している

## 交渉者としての心得

### 完璧と大雑把を行き来する

- 最初の提案やアイデア出しはたたき台として大雑把に
- 契約書や費用設計、宿題事項は完璧に仕上げる
- メリハリが重要

### 安心・安全・ポジティブな場作り

- 交渉相手を批判しない
- 秘密情報が漏洩しない安心できる環境を整える
- 互いの脳がフル回転し、前向きなアイデアが生まれる場を作る

### 余裕の笑顔をキープ

- 用意周到な事前準備があるからこそ余裕の笑顔でいられる
- ヘラヘラ笑うのではなく、やることをやった上での笑顔
- どきまぎやしかめっつらを見せた時点で敗色濃厚

### 「できません」ではなく代替案を

- 「できません!」と即答しない
- 「○○ならできます!」と代替案を提示する
- 全体のバランスを考えた柔軟な対応が交渉を成功に導く
